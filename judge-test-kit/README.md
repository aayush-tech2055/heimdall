# Heimdall judge test kit (Glimmora)

Everything needed to test Heimdall end to end on the live product: https://heimdall-chi-three.vercel.app

- `Heimdall_Round2_Submission.pdf` — the Round 2 submission: capabilities, evidence, an annotated tour of every screen, judge logins and the full test guide (Section 8).
- `Heimdall_Test_Kit.zip` — all test files below in one download.
- `1_admin/` — the Glimmora brand guideline (PDF and Markdown), 14 facts (CSV) and the approved logo.
- `2_creator/` — an ad script with planted mistakes (text and PDF), a poster, a 26-second video ad, a clean control script and a prompt-injection test.

Glimmora, Whitebay and Pearlo are fictional brands made for testing.
